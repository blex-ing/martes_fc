# MARTES FC v0.3.7 — Auditoría del Design System (issue #34)

## Inventario de CSS y mantenimiento
- PR #68: auditoría contra el React/TSX/HTML real. Las antiguas reglas `.score-grid`, `.score-stat`, `.keeper-identity`, `.keeper-avatar` y `.keeper-information` **ya se habían eliminado** en versiones previas y permanecen ausentes.
- El nuevo script `web/scripts/check-css-usage.mjs` impide introducir clases CSS huérfanas y se ejecuta dentro de `npm run check:design` durante CI.
- Conserva explícitamente los tonos `.tone-*` construidos dinámicamente y la API opt-in documentada `ui-glass-*`, `ui-button*`, `ui-chip` y `ui-soft-surface`; no se han eliminado selectores en uso.

## Reutilización de tokens
- Centralizado `--touch-target-min:44px` para las primitivas `ui-button` y `ui-hybrid-control` sin sustituir sus estilos de color o geometría.
- La CTA heredada `.primary-btn.ui-hybrid-control` **continúa con min-height:39px**, de acuerdo con la cascada original de `web/styles.css`. No se ha alterado su tamaño: la mejora táctil pendiente se documenta en la issue #37.
- Actualizada la documentación para especificar la exclusión obligatoria del Glass híbrido en hero, marcador y KPI, preservando sus pseudoelementos de iluminación.

## Verificación visual y limitaciones
- Capturas automáticas por ejecución Playwright: Inicio, Portería, Jugadores y modal en Chromium (320, 390, 768 y 1440 px) y WebKit móvil.
- Pruebas de radios, capa Glass, brillos, tonos dinámicos, `prefers-reduced-motion` y token táctil de primitivas.
- Las capturas de CI permiten revisión visual, pero **no son comparaciones de píxeles contra imágenes doradas**: incorporar y aprobar esos baselines, y probar Safari físico, sigue siendo trabajo distinto de QA.
- Sin cambios de Worker, D1, autenticación, dependencias, valores cromáticos, fuentes, padding, iluminación de hero/marcador/KPI o componentes de negocio.

- Publicación mediante PR `release/v0.3.7` a `master` con CI, Visual QA Chromium/WebKit y Cloudflare Workers Build aprobados.
