# MARTES FC v0.3.6 — Administración segura y accesible

## Correcciones de seguridad y mensajes (issue #35)
- PR #65: las operaciones administrativas requieren una respuesta JSON válida y `ok: true`; un formulario de Cloudflare Access, HTML o JSON malformado no puede interpretarse como escritura correcta.
- Mensajes claros y seguros para sesión caducada, origen rechazado, edición obsoleta, datos del partido/portero, jugador con historial, errores de red y temporada inválida. No se muestran códigos internos arbitrarios.
- Las solicitudes no modifican la autenticación, las políticas de Cloudflare Access ni las transacciones D1 existentes.

## Formularios y accesibilidad
- Confirmación explícita y reversible antes de eliminar jugadores, con controles accesibles en el panel. Ninguna eliminación se ejecuta al pulsar «Eliminar» por primera vez.
- Bloqueo síncrono de envíos duplicados, indicadores `aria-busy`, validación de nombres y fechas y mensajes de error visibles.
- Se preserva el comportamiento existente del foco del modal y los textos distintos para demostración local y datos compartidos.
- Cambio de estilos limitado al bloque de confirmación, usando tokens existentes del Design System; no se modifican los reflejos del hero ni los KPI.

## Verificación
- Pruebas de API: 200 HTML, JSON inválido, errores 401/403/409, red y respuestas de éxito.
- Playwright Chromium (1440, 768, 320 y móvil) y WebKit móvil: sesión denegada, eliminación, conflicto, restricción del portero, errores de red, fechas y foco.
- TypeScript, lint, pruebas de dominio/Worker, comprobación visual y build Cloudflare.
- Sin cambios de esquema ni migraciones D1; no copiar datos de preview a producción.
