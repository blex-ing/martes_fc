# MARTES FC v0.1.0 — Primer dashboard React público

## Contenido de la versión
- React 19 + TypeScript estricto + Vite para las pantallas de resumen, partidos, jugadores, portería y datos.
- Datos de demostración ficticios, con persistencia local validada; no hay acceso remoto a resultados reales.
- Registro de partidos, detalle de marcador, ranking de goleadores, apariciones y efectividad del portero.
- Diseño responsive Liquid Glass con tonos neón, mantenido desde la primera maqueta.
- Pruebas de dominio con Node y QA visual Playwright en Chromium para escritorio y móvil.
- CI con typecheck, ESLint, pruebas, build, auditoría npm y comprobación preventiva de privacidad.
- Dependabot semanal, pull requests, publicación de releases y limpieza segura de ramas.
- Preparación de configuración para Cloudflare Workers Builds.

## Seguridad y privacidad
El repositorio es público y solo muestra datos ficticios. No contiene contactos, claves, capturas del chat ni datos de pagos.
No existe backend, gestión remota, registro de usuarios ni cuentas. Toda edición se almacena únicamente en el navegador actual.

## Límites pendientes
- **No está desplegada en Cloudflare**. Conectar GitHub y verificar preview y producción después de publicar esta release.
- Configurar protección de ramas master/develop en GitHub Free (Settings → Branches).
- Cuando exista un backend, crear un API de lectura pública y escritura autenticada con datos privados separados.

## Pruebas
La publicación exige comprobaciones verdes en los PR de integración y release, sin omitir QA de móvil.
