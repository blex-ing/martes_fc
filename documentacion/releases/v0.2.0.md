# MARTES FC v0.2.0 — Estadísticas compartidas con administración segura

> **Candidato de release — NO publicado.** Preparado desde `develop` el 17-11-2026. No hacer merge a `master` ni crear tag mientras las puertas de publicación sigan abiertas.

## Cambios previstos
- Estadísticas compartidas entre dispositivos mediante Cloudflare Workers API y Cloudflare D1.
- Temporadas, plantilla de jugadores, partidos, participaciones y goles individuales persistidos con controles SQL.
- API pública `GET /api/public/snapshot` con únicamente resultados publicados y sin eventos de auditoría.
- Gestión de jugadores y resultados mediante rutas `/api/admin/*` protegidas por Cloudflare Access, con validación criptográfica RS256 de JWT, audiencia, emisor y correo.
- Mantiene demo local claramente identificada cuando los datos remotos no estén disponibles; conserva diseño adaptable y Liquid Glass.
- Base de datos de pruebas separada de producción. Registro privado de acciones administrativas.

## Cambios técnicos de compilación
- Se usa npm con esbuild directo; Vite y `@vitejs/plugin-react` ya no forman parte de las dependencias.
- Se conserva TypeScript estricto, aunque no todas las reglas que proporcionaba `typescript-eslint` permanecen; este cambio de cobertura queda documentado en `documentacion/MIGRACION_ESBUILD_SIN_PICOMATCH.md`.
- Se requiere comprobar la configuración de Cloudflare Access de **producción** antes de publicar la API admin.

## Seguridad y privacidad
Nunca publicar emails administrativos, claves de Access, JWT, cookies, identificadores privados de jugadores ni resultados personales sin permiso. El único contenido inicial de la migración es la temporada estructural 2026, sin nombres reales.
