# MARTES FC v0.3.3 — Limpieza segura de ramas fix/*

## Mejora de mantenimiento
- PR #55: el workflow de limpieza admite `fix/*` fusionadas hacia `develop`, además de `feature/*`.
- Se mantiene el borrado de `release/*` únicamente tras un PR fusionado hacia `master`.
- La eliminación comprueba que el PR se haya fusionado, que procede del mismo repositorio y que el SHA remoto coincide con el original del PR; usa `--force-with-lease` para preservar ramas con trabajo nuevo.
- Se actualiza `documentacion/FLUJO_GIT_Y_RELEASES.md` para reflejar este flujo.

## Alcance y seguridad
- Sin cambios de componentes, CSS, dependencias, esquemas D1, secretos o lógica de negocio.
- El workflow solo actúa en cierres futuros de PR por merge. No elimina automáticamente ramas `fix/*` ya fusionadas antes de esta versión.
- CI de calidad, auditoría, compilación, pruebas y Visual QA obligatorias antes de integrar a master.
