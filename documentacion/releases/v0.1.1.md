# MARTES FC v0.1.1 — Preparación del primer despliegue Cloudflare

## Cambios
- Metadatos públicos Open Graph para compartir correctamente la demo.
- Prueba Playwright de metadatos y mantenimiento de pruebas existentes.
- Diagnóstico documentado del error ENOENT de npm ejecutándose en la raíz.
- Comando ya configurado en Cloudflare por el propietario:
  cd web && npm ci --no-audit --no-fund && npm run build
- Versionado sincronizado en package.json y package-lock.json.

## Validaciones necesarias
- Checks de GitHub Actions en verde antes de fusionar la release.
- Después del merge, verificar en Cloudflare Workers Builds la compilación, el deploy y la URL real.
- La publicación de un tag GitHub **no demuestra por sí sola** que Cloudflare haya desplegado la aplicación.

## Limitaciones
- Estadísticas de ejemplo inventadas, persistencia local.
- Sin datos compartidos, sin backend y sin autenticación.
